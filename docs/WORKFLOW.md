# REAX Editor Workflow

A typical workflow in REAX:

## 1. Start a project
- Open https://reax.ndkdev.tech
- Start from a blank composition or a template/preset

## 2. Import audio
- Upload your track
- Use playback/scrub to preview timing
- Apply trim or playback-rate adjustments if needed

## 3. Build the scene
- Add layers (visualizer, radial wave, particles, image, text, shapes)
- Arrange layer order and transforms
- Configure colors, sizes, opacity, and visual style per layer

## 4. Tune audio reactivity
- Choose reaction bands (bass/mids/highs/all)
- Adjust sensitivity/smoothing and beat-related settings
- Refine scene effects (blur/shake/punch/mirror options where available)

## 5. Preview and refine
- Play through key sections (drops, kicks, transitions)
- Adjust timing, layer balance, and visual intensity

## 6. Export
- Export the final music video from the studio when the composition is ready
